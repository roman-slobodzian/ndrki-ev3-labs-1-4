# EV3 labs in C#

Minimal .NET 10 console project for the EV3 assignments in [lab-part-1.md](lab-part-1.md). It references `Ev3.Framework` for future communication with an EV3 running its standard firmware.

```sh
dotnet restore
dotnet build
dotnet run
```

`Program.cs` is intentionally empty. Add each lab's code when you are ready to implement it.
